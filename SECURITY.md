# Security Policy 🛡️

## Supported Versions

We actively monitor and support the following versions of Justsent with security updates:

| Version | Supported |
| ------- | --------- |
| v0.1.x  | ✅ Yes    |
| < v0.1  | ❌ No     |

---

## Reporting a Vulnerability

We take the security of Justsent seriously. If you find a security vulnerability, please do **not** open a public GitHub issue. Instead, report it responsibly:

1. **Submit Report**: Send an email detailing the vulnerability to `security@justsent.com` (or contact the repository maintainers directly).
2. **Details to Include**:
   - A description of the vulnerability and its potential impact.
   - Detailed step-by-step instructions to reproduce the issue (including proof-of-concept scripts or configurations if applicable).
   - The version of Justsent, operating system, and hardware details you tested on.
3. **Response Time**: We will acknowledge receipt of your report within 48 hours and work with you to analyze and verify the issue.
4. **Resolution & Disclosure**: We will attempt to resolve the issue as quickly as possible and will coordinate a public disclosure timeline with you once a patch has been merged and released.

Thank you for helping keep Justsent secure! 🔒
