# System Architecture Document

This document outlines the detailed system design, component boundaries, and lifecycle mechanisms of **Justsent**.

---

## 🗺️ Architectural Boundaries

Justsent is structured as three isolated layers that communicate over standard IPC (Inter-Process Communication) and HTTP APIs:

```
+------------------------------------------------------------------------+
|                               TAURI APPS                               |
|                                                                        |
|  +---------------------------+          +---------------------------+  |
|  |       React UI            |          |         Tauri Rust        |  |
|  |  - State management       |   IPC    |  - Window controller      |  |
|  |  - Drag-and-drop handles  |<-------->|  - Sidecar orchestrator   |  |
|  |  - Custom CSS layouts     |          |  - Native folder reveals  |  |
|  +---------------------------+          +---------------------------+  |
+-------------------------------------------------------|----------------+
                                                        |
                                                        | Sidecar Spawn
                                                        v
+------------------------------------------------------------------------+
|                              GO BACKEND                                |
|                                                                        |
|  +------------------------------------------------------------------+  |

|  |  - Custom HTTP router (net/http)                                 |  |

|  |  - Zero-allocation chunked file streamer                         |  |
|  |  - Cloudflared tunnel process wrapper                            |  |
|  +------------------------------------------------------------------+  |
+------------------------------------------------------------------------+
```

## 1. Process Lifecycle Orchestration

To prevent orphaned processes and memory leaks on the user's desktop, Justsent uses a dual-heartbeat termination protocol:

1. **Tauri-level termination**: When the Tauri application window is closed, Tauri terminates the spawned Go sidecar binary.
2. **Orphan check fallback**: In the event that the Tauri app crashes or is force-killed, the Go backend runs a background monitor goroutine:
   - On launch, Go fetches its parent Process ID (PPID) via `os.Getppid()`.
   - Every second, it polls `os.Getppid()`.
   - If the PPID changes to `1` (init) or does not match the initial PPID, Go detects that the parent Tauri app has terminated, executes a cleanup of active Cloudflare tunnels, and exits gracefully:
     ```go
     initialPPID := os.Getppid()
     for range time.NewTicker(1 * time.Second).C {
         if os.Getppid() == 1 || os.Getppid() != initialPPID {
             tunnel.Release() // Terminate active tunnels
             os.Exit(0)
         }
     }
     ```

## 2. File Streaming & Range Requests

Justsent does not upload files to intermediate servers. Instead, it streams files directly from the host's filesystem to the downloader's browser.
- **Zero-Memory Overhead**: Files are served using `http.ServeContent` which supports HTTP Range requests (crucial for resume operations, media scrubbing, and high-speed downloads).
- **Embedded Web Templates**: The Go backend embeds the static HTML download pages. When a downloader visits the sharing URL, Go serves this embedded page, prompts for a password (if set), and starts streaming the file upon approval.

---

## 3. SQLite Database

The Go backend stores configuration metadata, active transfers, and download histories in a local, single-file SQLite database located in the app data directory.

---

## 4. Tunnel Lifecycle (Cloudflared Integration)

- **Internet Sharing**: Justsent wraps the official `cloudflared` binary.
- **Quick Tunnels**: When the user toggles Over the Internet sharing, Go spawns `cloudflared tunnel --url http://localhost:[Port]` in the background.
- **Output Scraping**: Go monitors the stderr output of the `cloudflared` process. It uses a regular expression to locate the dynamic `.trycloudflare.com` URL generated by Cloudflare's quick tunnel service and returns this link back to the React frontend.
- **Cleanup**: Stopping a share kills the specific `cloudflared` process, closing the tunnel immediately.
